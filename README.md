# Telecom-Customer-Churn-Analytics
📊 Telecom Customer Churn & Retention Analytics

This project analyzes customer churn for a telecom company to identify why customers leave, which customer segments are at highest risk, and how churn impacts recurring revenue.

The analysis covers 7,043 customers and combines Python, SQL, Excel, and Power BI to create an end-to-end data analytics workflow.

🔍 Key Analysis
Overall customer churn and churn rate
Churn by contract type
Churn by tenure
Churn by payment method
Churn by internet service
Churn by technical support
Churn by online security
Monthly revenue lost from churn
Revenue lost by contract
High-risk customer identification
Revenue-at-risk customer segments
