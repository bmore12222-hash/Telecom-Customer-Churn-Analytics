# E-commerce Sales Analysis & Dashboard

An end-to-end data analytics project focused on analyzing e-commerce sales performance using Excel, SQL, Python, and Power BI.

## Project Overview
This project demonstrates the complete data analysis workflow, from data preparation and exploratory analysis to SQL-based querying and interactive dashboard development.

## Tools & Technologies
- **Excel:** Data organization, KPI summaries, and reporting
- **SQL:** Data querying, aggregations, and sales analysis
- **Python:** Data cleaning, preprocessing, and exploratory data analysis
- **Power BI:** Interactive dashboard design and sales performance visualization

## Project Objectives
- Analyze sales performance and identify trends.
- Evaluate product and category performance where supported by the dataset.
- Track key performance indicators and support business reporting.
- Present findings through an interactive dashboard.
- Demonstrate an end-to-end data analytics workflow.

## Skills Demonstrated
Data Cleaning | Exploratory Data Analysis | SQL Querying | KPI Reporting | Data Visualization | Business Intelligence | Dashboard Development

## Business Value
The project illustrates how raw sales data can be transformed into structured reports and interactive visualizations to support business analysis and decision-making.
